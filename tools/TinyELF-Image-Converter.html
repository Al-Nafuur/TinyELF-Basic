    Load it on the Atari
    1. Save the listing as a text file with an 8.3 name, for example SAMPLE.BAS.
    2. Copy the file to the SaveKey with SaveKey-Manager (drive E1).
    3. In TinyELF Basic type NEW, then ENTER "E1:SAMPLE.BAS", then RUN.

    Downloads are blocked inside this viewer. Copy the listing, or open the HTML file directly in a browser to download it.

    The 2600 draws at most 160 pixels per line. TinyELF's GRAPHICS 8 places 18 player columns on 145 PLOT positions; 6 of them are always dark, and every 13th line is the blank gap between two text rows. The converter samples the picture on exactly this grid, so any image size works: a 288 × 192 picture is scaled down to 145 columns. The kernel draws each lit pixel in every second frame and changes the background only every second line, so the TV blends neighbouring colours; Simulate the TV shows that mix.
